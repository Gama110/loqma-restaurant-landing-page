# Loqma Restaurant Landing Page

A technical repository containing the source code for a responsive front-end landing page developed for "LOQMA Restaurant" (A commercial burger and fast-food concept located in Egypt).

## Live Demo

- Live Demo: [View Live Site](https://gama110.github.io/loqma-restaurant-landing-page/)

---

## Technical Specifications

- **Responsiveness:** Full multi-device layout configuration optimized for mobile, tablet, and desktop viewports using CSS flexible box mapping.
- **Navigation:** Semantic header positioning with embedded internal page-anchor routing (`#hero`, `#menu`, `#features`, `#about`, `#contact`).
- **Integrations:** Live actionable endpoints connecting the user interface directly to the WhatsApp API framework and the `tel:` device communication protocol.
- **Localization:** Engineered for standard Arabic Right-to-Left (`dir="rtl"`) textual rendering with cross-browser responsive typography components.
- **SEO Optimization:** Formatted with baseline document metadata and Open Graph (OG) object properties to ensure proper indexation and rich media layout generation during hyperlink distribution.

---

## Tech Stack

- **HTML5:** Structural layout generation utilizing semantic web architecture elements.
- **CSS3:** Native styling properties, custom color layout definitions, interface reset logic, and media query declarations.
